# Afisha Loyalty Analysis

Проект посвящён анализу пользовательского поведения в сервисе покупки билетов.

## Цель проекта

Исследовать поведение пользователей и выявить факторы, влияющие на повторные покупки и лояльность клиентов.

## Основные задачи

- предобработка и очистка данных;
- анализ пользовательской активности;
- исследование повторных заказов;
- анализ выручки и количества билетов;
- изучение влияния устройств, регионов и категорий мероприятий;
- поиск факторов, связанных с возвратом пользователей.

## Используемые технологии

- Python
- Pandas
- NumPy
- SQLAlchemy
- PostgreSQL
- Matplotlib
- Seaborn
- Phik
- Jupyter Notebook

## Структура проекта

- `analysis.ipynb` — основной ноутбук с анализом;
- `requirements.txt` — список зависимостей;
- `.gitignore` — исключения Git;
- `.env` — переменные окружения (не загружается в репозиторий).
